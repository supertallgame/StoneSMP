Community Guidelines

Server Rules

Click any rule item to view detailed policy descriptions for Season 2.

Teams, alliances, or clans cannot exceed 5 total members. Cross-teaming during fights, raids, or event battles with non-team members is strictly forbidden.
All bases and player activity must remain within the 7.5k x 7.5k world border bounds. Attempting to glitch outside or build beyond border limits will result in base removal.
Hacked clients, X-Ray packs, auto-clickers, and exploits are strictly prohibited. Offenders will receive permanent bans without warning.
Item duplication or abusing server glitches is disallowed. Use /report immediately if you encounter any bugs.
